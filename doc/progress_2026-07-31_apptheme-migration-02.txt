WAS BEWUSST LITERAL BLEIBT
--------------------------------------------------------------------------
  SelectiveAlphaEditor.canvasBg1/bg2 = rgb(200,200,200) / rgb(160,160,160)
    *** KEINE Tokens. Der Benutzer waehlt diese Farben zur Laufzeit ueber
        den Hintergrund-Dialog, AppSettings.bg1/bg2 speichert sie. Die
        Werte im Code sind nur Startwerte, bis die Einstellungen geladen
        sind. Ein Token ist eine Design-Entscheidung, keine
        Benutzereinstellung (§21/§31). Als Kommentar im Code vermerkt. ***
  UIBuilder: new BasicStroke(2, CAP_ROUND, JOIN_ROUND, 0, dash, 0)
    Gestrichelter Rahmen der Ablageflaeche. Traegt ein dash-Array und
    Cap/Join — daraus wird kein einfaches STROKE_*-Token.
  SelectiveAlphaEditor.RULER_THICK = 20
    Bereits benannte Konstante am fachlich richtigen Ort. Sie nach AppTheme
    zu kopieren wuerde eine zweite Quelle schaffen.
  UIComponentFactory: 2 parametrisierte Fonts (aus Datei 1)
